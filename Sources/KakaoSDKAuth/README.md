# KakaoSDKAuth

사용자 인증 및 토큰 관리 모듈입니다.

## Requirements
- iOS 15.0
- Swift 5.8

## Dependencies
- KakaoSDKCommon

## Installation
```swift
.package(url: "https://github.com/kakao/kakao-ios-sdk.git", from: "2.0.0")
```
2.x.x 버전을 사용합니다. 타겟의 Dependencies에 `KakaoSDKAuth`을 추가합니다.

## Import
```
import KakaoSDKAuth
```
